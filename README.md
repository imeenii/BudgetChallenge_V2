# 💰 Budget Challenge

### Simulateur de décisions financières – Application Android

## 👩‍💻 Réalisé par : Imene Zrig

**Spécialité :** Génie Logiciel – 3ᵉ année  
**Année universitaire :** 2026–2027

## 📌 Présentation du projet

Budget Challenge est une application mobile Android développée dans le cadre d'un projet académique.

Elle permet à l'utilisateur de gérer un budget mensuel fictif, de suivre ses dépenses, de prendre des décisions financières et de faire face à des événements imprévus.

L'objectif est d'aider l'utilisateur à comprendre les conséquences de ses choix financiers et à atteindre un objectif d'épargne.

## 🎯 Objectifs

- Gérer un revenu et différentes catégories de dépenses.
- Calculer le solde budgétaire.
- Définir un objectif d'épargne.
- Simuler des décisions financières.
- Faire face aux événements imprévus.
- Analyser l'évolution du budget.
- Suivre les résultats mensuels.

## ✨ Fonctionnalités

- Configuration du budget mensuel.
- Calcul automatique des dépenses et du solde.
- Détection des budgets déficitaires, équilibrés et excédentaires.
- Simulation de décisions financières.
- Comparaison de plusieurs stratégies budgétaires.
- Génération aléatoire d'événements imprévus.
- Gestion de l'épargne cumulée.
- Suivi des résultats mensuels.
- Analyse et recommandations budgétaires.

## 🏗️ Structure du projet

| Classe | Description |
|---|---|
| `MainActivity` | Écran principal de l'application. |
| `BudgetActivity` | Configuration du budget. |
| `DashboardActivity` | Tableau de bord budgétaire. |
| `DecisionsActivity` | Gestion des décisions financières. |
| `EventActivity` | Gestion des événements imprévus. |
| `AnalysisActivity` | Analyse budgétaire. |
| `Budget` | Modélisation du budget. |
| `Event` | Modélisation des événements. |
| `MonthlyResult` | Résultats mensuels. |
